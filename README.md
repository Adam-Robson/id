# LE FOG WEBSITE

[![CI](https://github.com/Adam-Robson/id/actions/workflows/node.js.yml/badge.svg)](https://github.com/Adam-Robson/id/actions/workflows/node.js.yml)

This is the repository for the website for the
band LE FOG. Run the development server after
pulling down the source code.

```bash
npm run dev
```

Open [localhost](http://localhost:3000) on port
3000 with your browser to view the site locally.

You can start editing the home page by modifyin1g
`src/app/page.tsx`. The page auto-updates as you
edit the file.

## Deployed on Vercel

The deployment is on the [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme).
